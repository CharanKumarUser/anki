## 🌟 Why this was created
The original `.apkg` flashcard file was **443 MB**, making it very slow or impossible to import and study on mobile devices (phones, tablets, iPads) without storage errors or requiring expensive third-party apps.

This portal solves that by providing:
1. **Zero-install Web Application**: Study immediately in **any browser** on your phone, tablet, iPad, Mac, or PC.
2. **On-demand Media Loading**: Only loads images for questions you are viewing—no massive 450 MB upfront downloads!
3. **Downloadable PDF Booklets**: Clean, printable PDF question booklets with answers and explanations ready for offline reading.
4. **Interactive Modes**: Flashcard flip mode, Practice Quiz mode with scoring, and full Q-Bank List mode.

## 🚀 Live Access & How to Run

### Option 1: GitHub Pages (Instant Online Access on Any Phone/Tablet)
1. In this repository, go to **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &gt; **Branch**, select `main` and root `/`.
3. Click **Save**.
4. Within 1 minute, your site will be live at:
   ```
   https://charankumaruser.github.io/anki/
   ```
   *Your sister can open this URL directly in Chrome or Safari on her mobile phone or tablet to start studying instantly!*

### Option 2: Run Locally on Laptop / PC
Double click `index.html` or start a lightweight local web server:
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`

## 📚 Features & Capabilities

| Feature | Description |
| :--- | :--- |
| **🗂️ Flashcard Mode** | Classic Anki-style flip cards. View question and options, press **Space** or click to reveal the verified answer, clinical explanation, and textbook references. |
| **📝 Practice Quiz Mode** | Interactive multiple-choice testing. Click your answer to see instant feedback (green if correct, red if incorrect), automatic scorecard, and accuracy percentage. |
| **📜 Q-Bank List Mode** | Continuous scrollable question bank view for all questions in the chosen subject. Expand/collapse all explanations with one click. |
| **🖨️ Instant Print to PDF** | Click **"Print PDF"** at any time. Features custom `@media print` styling that formats the deck into an official examination paper booklet ready to save as PDF. |
| **📥 Pre-built PDF Downloads** | Direct PDF booklets available in the `pdfs/` directory with questions, diagrams, answers, and explanations. |
| **⭐ Bookmarks / Favorites** | Star difficult or high-yield questions (press `S`). Filter to study only your bookmarked cards at any time. Saved in browser storage. |
| **🌓 Dark & Light Themes** | Eye-friendly dark mode for late-night study sessions. Automatically remembers your preference. |
| **🔍 Real-Time Global Search** | Search through all 5,540 questions by keywords, question ID (e.g. `MC5206`), or topics. |
| **🖼️ Image Lightbox** | Click on any clinical photograph, MRI, CT scan, or histological diagram to view it full-screen with high-resolution zoom. |

## ⌨️ Keyboard Shortcuts

| Key | Action |
|:---|:---|
| <kbd>&rarr;</kbd> or <kbd>J</kbd> | Next Question |
| <kbd>&larr;</kbd> or <kbd>K</kbd> | Previous Question |
| <kbd>Space</kbd> or <kbd>Enter</kbd> | Reveal Answer & Explanation / Flip Card |
| <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd>, <kbd>4</kbd> | Select Option A, B, C, D in Quiz Mode |
| <kbd>S</kbd> | Star / Bookmark current question |
| <kbd>R</kbd> | Shuffle / Randomize deck order |
| <kbd>/</kbd> | Jump to search bar |
| <kbd>Esc</kbd> | Close image lightbox or modal |

## 📄 Generating PDF Booklets

You can generate printable PDF booklets for any subject on your local machine using Chrome / Edge:

```bash
# Generate PDF for a specific subject (e.g. Anatomy)
python generate_pdfs.py anatomy

# Generate PDFs for all 19 subjects
python generate_pdfs.py all
```
The resulting PDFs are saved directly to the `pdfs/` directory with clean formatting and pagination.
